# FAIR CRM — Responsive UI Reference

**Status:** Supporting pointer — not a second canonical UI standard.

The binding FAIR CRM responsive/UI rules live in:

- [FRONTEND_UI_MASTER_STANDARD.md](FRONTEND_UI_MASTER_STANDARD.md) — Fair CRM component, table, breakpoint, responsive and Visual QA implementation rules.
- [../../../standards/ui/UI_FOUNDATION_STANDARD.md](../../../standards/ui/UI_FOUNDATION_STANDARD.md) — reusable KYROX UI foundation.

This file remains only to preserve existing links from ADRs/history. **Do not add new responsive rules here.** Update the Fair CRM UI Master Standard when the behavior is product-specific, or the shared UI Foundation Standard when the rule should apply unchanged to future KYROX products.
